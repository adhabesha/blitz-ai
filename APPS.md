# Blitz AI desktop and Android apps
Run go.ps1 (see the chat instructions). It updates the code, deploys to Render, switches on email sign-in, builds the Windows .exe and the Android .apk on GitHub, and downloads them to Downloads\Blitz-AI-Apps.
Admin console: https://YOUR-APP.onrender.com/admin (also Ctrl+Shift+A in the desktop app). Needs the email in ADMIN_EMAILS (go.ps1 sets it).
